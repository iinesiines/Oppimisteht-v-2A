# Nordic Notes — Oppimistehtävä 2A / CSS Grid

## Sivun avaaminen
Avaa `index.html` suoraan selaimessa. Kuvitus ja Font Awesome -ikonit sisältyvät kansioon, joten sivu toimii myös ilman internetyhteyttä.

## Julkaisu GitHub Pagesissa
1. Luo GitHubiin uusi julkinen repositorio, esimerkiksi `css-grid-2a`.
2. Siirrä **tämän kansion sisällä olevat tiedostot ja kansiot** repositorion juureen: `index.html`, `styles.css`, `assets/`, `styles/`, `fonts/`.
3. GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
4. Avaa julkaistu osoite ja tarkista kuvat, navigointi ja asettelu kolmessa näyttökoossa.
5. Kopioi **todellinen toimiva URL** analyysiraportin kysymyksen 1 vastaukseen. Älä palauta esimerkkiosoitetta.

## Rakenne ja arviointikriteerit
- CSS Grid ja **grid-template-areas** kaikissa näyttökoissa.
- Suuri näyttö yli 900 px: navigaatio + 4 korttia/rivi + 2 mainosta.
- Tabletti 601–900 px: navigaatio + 2 korttia/rivi + 2 mainosta.
- Mobiili korkeintaan 600 px: navigaatio + 1 kortti/rivi + 2 mainosta peräkkäin.
- 12 kuvaa, alt-tekstit, otsikon taustakuva ja mainoskuvat teksti-overlayllä.
- Navigointilinkit Font Awesome -ikoneilla, pienennetty typografia/padding mobiilissa.
- Selkeät HTML5-elementit, CSS-kommentit, responsiivisuus ja näppäimistökäytettävyys.

## Käytä tekoälyä avoimesti
Koodi ja paikalliset SVG-kuvitukset on tuotettu ChatGPT:n avustuksella. Raportin oman tekemisen ja oppimisen kohdat on tarkistettava ja tarvittaessa muokattava vastaamaan sitä, mitä oikeasti teit. Helppoja omia jatkomuokkauksia: vaihda yhden kortin teksti, säädä `:root`-värimuuttujia tai muuta `.kortti-kuva`-elementin `aspect-ratio`-arvoa.
